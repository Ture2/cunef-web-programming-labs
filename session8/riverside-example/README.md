This worked example is the static React port of the Block I Riverside FC site. All data comes from hard-coded local constants — no backend is needed to run the app.

The `backend/` folder is included for reference so you can compare the real data shape used in session 9 and 10.

## Run the frontend

```powershell
npm install
npm run dev   # http://localhost:5173
```

## (Optional) Run the backend

```powershell
cd backend
npm install
npm start     # http://localhost:3000
```
